# CSCI3320_Project
Group Project on Processing Data Records on a File (100 Points)
Problem: Write a program that processes an inventory data file which has – description (name of the coffee) and quantity of the coffee (number of pounds); compute the following:
•	Write a function to add records to a data file.
•	Write a function that displays all the records in the inventory file.
•	Write a function that can modify both description & quantity of a record.
•	Write a function that can delete a record from the inventory file.
•	Write a function that can delete a record from the inventory file.
•	Write a function that can search for a record in the inventory file by description .
Write a main program to test all the created functions and submit your solution and output by due date & time.
Due date: 10/13/2026 by 11:10 AM
